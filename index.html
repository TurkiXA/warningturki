نظام إنذار الحركة الذكي

نظام متكامل يكتشف الحركة عبر حساسات PIR، يرسل إشعاراً فورياً إلى Telegram مع تحديد رقم الحساس، ويولّد تقارير دورية تلقائية تعمل بالكامل على السحابة.

ما هو النظام؟

نظرة شاملة على الفكرة والمعمارية وكيف تترابط المكونات.

الفكرة الأساسية

النظام عبارة عن منظومة إنذار حركة ذكية للمخيم تعتمد على إنترنت الأشياء. يكتشف الحركة عبر حساسَين PIR موصولَين بمتحكم ESP32-S3، ثم يُرسل إشعاراً فورياً إلى مجموعة Telegram يحدد أي حساس تحرك. يحتفظ النظام بعدد الحركات ويولّد تقارير يومية وأسبوعية وشهرية وسنوية تقارن الفترة الحالية بالسابقة، مع تقرير أسبوعي تلقائي كل يوم جمعة الساعة 12 ظهراً.

الطبقات الثلاث

طبقة الاستشعار

جهاز ESP32-S3 متصل بحساسَين PIR يقرآن الحركة ويحددان أي حساس تحرك، ثم يرسل طلب HTTPS إلى السحابة.

Sensor Layer

الطبقة السحابية

Cloudflare Worker يستقبل الطلبات، يتحقق من مفتاح الأمان، يحدّث العدادات في D1، ويولّد التقارير.

Cloud Layer

طبقة الإشعارات

مجموعة Telegram تستقبل الإشعارات النصية، وتدعم أوامر التقارير الفورية.

Notification Layer
آلية العمل

تدفق العمل خطوة بخطوة

مسار الحدث من لحظة اكتشاف الحركة حتى وصول الإشعار إلى هاتفك.

1

اكتشاف الحركة

حساس PIR يكتشف حركة أمامه، فيرسل إشارة رقمية (HIGH) إلى ESP32-S3.

2

إرسال للـ Worker

ESP32-S3 يرسل طلب POST آمن يحتوي على رقم الحساس إلى Cloudflare Worker.

3

تسجيل وإشعار

Worker يسجل الحركة في D1، يحفظ وقت آخر حركة، ويرسل إشعاراً نصياً إلى Telegram مع رقم الحساس.

4

التقارير التلقائية

Cron Trigger يرسل تقريراً أسبوعياً كل جمعة الساعة 12 ظهراً بتوقيت السعودية.

5

التقارير الفورية

يمكن طلب تقرير فوري من داخل المجموعة عبر أوامر مثل /أسبوعي أو /شهري.

العتاد والتوصيل

تفاصيل العتاد والتوصيلات

نوع المتحكم، نوع حساس PIR، والتوصيلات الدقيقة لكل قطعة.

نوع المتحكم (ESP)

ESP32-S3 Dev Board — متحكم حديث يدعم Wi-Fi وBluetooth، مع عدد كافٍ من منافذ GPIO لقراءة حساسَي PIR وإرسال الطلبات إلى السحابة عبر HTTPS.

  • معالج ثنائي النواة بتردد 240MHz
  • ذاكرة RAM كافية للاتصال الآمن
  • دعم أصلي لـ TLS/HTTPS
  • منافذ GPIO متعددة (نستخدم GPIO 11 و 10)

نوع حساس PIR

HC-SR501 — حساس حركة سلبي (Passive Infrared) يعمل بجهد 5 فولت، ويُخرج إشارة رقمية:

  • HIGH عند اكتشاف حركة (لفترة قابلة للضبط)
  • LOW عند عدم وجود حركة
  • يحتوي على مقاومتين متغيرتين لضبط الحساسية وزمن التأخير
  • زاوية كشف تصل إلى 110 درجة
  • مدى كشف يصل إلى 7 أمتار

توصيل ESP32-S3 مع حساسَي PIR

توصيل بسيط جداً: كل حساس له 3 أطراف فقط (VCC، GND، OUT).

حساس PIRESP32-S3ملاحظات
VCC (كلا الحساسين)5V أو 3.3Vيُفضّل 5V لأداء أفضل
GND (كلا الحساسين)GNDأرضي مشترك
OUT (الحساس 1)GPIO 11إشارة الحساس الأول
OUT (الحساس 2)GPIO 10إشارة الحساس الثاني

ملاحظة: اترك الحساسات مستقرة لمدة دقيقة قبل بدء الاستخدام لتجنب الإنذارات الكاذبة (موجود في الكود).

إعدادات Cloudflare

كيف تضيف الأسرار (Secrets) في Cloudflare؟

خطوات دقيقة لإعداد المتغيرات السرية التي يحتاجها الكود.

ادخل إلى لوحة تحكم Cloudflare

اذهب إلى Workers & Pages، واختر الـ Worker الخاص بك (مثلاً camp).

افتح إعدادات المتغيرات

من القائمة الجانبية، اختر Settings ثم Variables and Secrets.

أضف سر البوت (TELEGRAM_BOT_TOKEN)

اضغط Add واختر Secret. الاسم: TELEGRAM_BOT_TOKEN. القيمة: التوكن الخاص بالبوت (الذي أخذته من BotFather).

أضف معرف المجموعة (TELEGRAM_CHAT_ID)

اضغط Add واختر Secret. الاسم: TELEGRAM_CHAT_ID. القيمة: معرف المجموعة (يبدأ بـ -100).

أضف مفتاح الأمان (ALARM_KEY)

اضغط Add واختر Secret. الاسم: ALARM_KEY. القيمة: my-secret-123 (أو أي قيمة سرية تختارها، وتضعها نفسها في كود ESP32).

انشر التغييرات

بعد إضافة كل الأسرار، اضغط على زر Deploy (أو Save and Deploy) في أعلى صفحة الـ Worker.

دليل الإنشاء

خطوات إنشاء المشروع من الصفر

دليل عملي لإنشاء البوت، الحصول على معرف المجموعة، ورفع الكود.

تحميل وتثبيت Arduino IDE

قم بتحميل Arduino IDE من الموقع الرسمي arduino.cc وتثبيته على جهازك.

إضافة دعم لوحات ESP32

افتح Arduino IDE، اذهب إلى File → Preferences. في خانة Additional Boards Manager URLs، أضف الرابط التالي:

https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json

ثم اذهب إلى Tools → Board → Boards Manager، ابحث عن esp32 (من Espressif Systems) وثبّته.

اختيار اللوحة والمنفذ

من قائمة Tools → Board، اختر ESP32S3 Dev Module. ثم من Tools → Port، اختر المنفذ الذي يظهر (مثلاً COM3 أو COM8).

نسخ كود ESP32-S3 ورفعه

افتح الكود الذي في القسم السابق (كود ESP32-S3)، وانسخه في Arduino IDE. غيّر ssid و password و workerUrl و alarmKey حسب بياناتك. ثم اضغط زر Upload (السهم المتجه لليمين).

إنشاء بوت Telegram

افتح Telegram وابحث عن @BotFather. أرسل /newbot، اختر اسماً واسم مستخدم ينتهي بـ bot. احفظ التوكن (Token) الذي سيعطيك إياه — هذا هو TELEGRAM_BOT_TOKEN.

إنشاء مجموعة وإضافة البوت

أنشئ مجموعة جديدة في Telegram. أضف البوت إليها. في BotFather، تأكد من تفعيل Allow Groups عبر /mybots ← Bot Settings ← Allow Groups ← Allow.

الحصول على معرف المجموعة (CHAT_ID)

أرسل رسالة في المجموعة تحتوي على @اسم_البوت. ثم افتح في المتصفح:

https://api.telegram.org/bot<BOT_TOKEN>/getUpdates

ابحث عن "chat":{"id":-100...} واحفظ الرقم — هذا هو TELEGRAM_CHAT_ID.

إنشاء قاعدة بيانات D1

في لوحة Cloudflare → Storage & Databases → D1 SQL Database → Create. افتح Console ونفّذ:

CREATE TABLE IF NOT EXISTS motion_counts (week_key TEXT PRIMARY KEY, count INTEGER DEFAULT 0);
CREATE TABLE IF NOT EXISTS system_state (key TEXT PRIMARY KEY, value TEXT);

إنشاء Worker وربطه بـ D1

في Cloudflare → Workers & Pages → Create → Worker. اربط D1 من Settings → Bindings باسم DB. ثم أضف المتغيرات من Variables and Secrets (كما في قسم "كيف تضيف الأسرار" أعلاه).

نشر كود Worker

الصق كود Worker في محرر الـ Worker، واضغط Deploy. ثم أضف Cron Trigger من Settings → Triggers بالقيمة:

0 9 * * FRI

(هذا يعني 9 صباحاً UTC = 12 ظهراً بتوقيت السعودية)

تعيين Webhook للبوت

افتح في المتصفح (استبدل القيم):

https://api.telegram.org/bot<BOT_TOKEN>/setWebhook?url=https://YOUR_WORKER.workers.dev/webhook

الاختبار

افتح Serial Monitor في Arduino IDE بسرعة 115200. انتظر WiFi connected وReady. مرّر يدك أمام الحساس الأول — يجب أن يظهر Sensor 1 → 200 وتصل رسالة في المجموعة. ثم أمام الحساس الثاني — Sensor 2 → 200.
